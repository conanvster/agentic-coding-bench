## Чому ліміт відповіді не головне

Усі 13 обірваних відповідей gemma (8192 токени) — **цикли в роздумах** («Actually, I'll try to run it.» сотні разів),
жодна не була корисним довгим текстом. Звичайні відповіді: медіана 255, p90 1164 токени. Більший ліміт лише
подовжить цикл. Лікування — семплер (DRY / repeat) — **перевірити replay_loops.py до прогону**.

## Ще треба (GPU вільний — після gpt-oss)

1. Стеля контексту gemma Q4_0 + mmproj на CPU: 79 872 → спробувати 83 968 (стеля 30.10 без mmproj). Модель вміє 262 144.
2. replay_loops.py: base / DRY 0.8 / DRY 0.5 по 2 рази на 13 випадків → обрати семплер, записати в model-rules gemma.
3. Димовий прогін (1 етап, 3) — переконатися, що OpenCode передає моделі MCP-картинку (ще НЕ перевірено в OpenCode).
